# 🌿 Kalu Hanga Meditation Center

> "Quiet the mind, and the soul will speak."

A serene, modern static website for the Kalu Hanga Meditation Center, located by the tranquil Kalu Hanga river in Sri Lanka. This project showcases a responsive landing page designed to provide information about meditation retreats, coaches, and the peaceful environment.

![Hero Image](https://images.unsplash.com/photo-1472214103451-9374bd1c798e?q=80&w=2070&auto=format&fit=crop)

## ✨ Features

-   **Responsive Design**: Fully adaptable layout for mobile, tablet, and desktop devices.
-   **Smooth Animations**: Elements gently fade in and slide up as you scroll (`IntersectionObserver`).
-   **Interactive Mobile Menu**: A sleek hamburger menu for easy navigation on small screens.
-   **Google Maps Integration**: Embedded map to help visitors locate the center easily.
-   **Modern UI**: Uses a calming color palette (Forest Green, Earthy Sand) and typography to reflect the meditation theme.
-   **SEO Optimized**: Includes Open Graph tags for better social media sharing.

## 🛠️ Technologies Used

-   **HTML5**: Semantic markup for accessibility and structure.
-   **CSS3**: Custom properties (variables), Flexbox, Grid, and media queries for styling.
-   **JavaScript (ES6+)**: Vanilla JS for the mobile menu toggle and scroll animations.
-   **Font Awesome**: For icons (social media, contact info).
-   **Google Fonts**: 'Playfair Display' for headings and 'Lato' for body text.

## 🔧 Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/kalu-hanga-meditation.git
    ```

2.  **Open the project:**
    Navigate to the project folder and open `index.html` in your web browser.

    ```bash
    cd kalu-hanga-meditation
    # On Windows
    start index.html
    # On Mac
    open index.html
    # On Linux
    xdg-open index.html
    ```

## 🌍 Deployment

This repository includes a GitHub Actions workflow (`.github/workflows/static.yml`) to automatically deploy to GitHub Pages.

1.  Push your changes to the `main` branch.
2.  Go to **Settings** > **Pages** in your GitHub repository.
3.  Ensure **Source** is set to "GitHub Actions".
4.  Your site will be live in a few minutes!
